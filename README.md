# Expedientes Jurídicos

Sistema web para la gestión y organización de expedientes jurídicos.

## Descripción

Expedientes Jurídicos es una herramienta diseñada para facilitar el registro, consulta y organización de información relacionada con expedientes legales.

## Funciones

- Registro de expedientes.
- Consulta de expedientes.
- Organización de información jurídica.
- Identificación mediante nombre o número de expediente.
- Interfaz sencilla y fácil de utilizar.
